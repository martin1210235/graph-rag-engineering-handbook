# Source and reuse notes

## NASA Systems Engineering Handbook

The sample passages in `data/knowledge.json` are excerpts from:

Hirshorn, S. R., Voss, L., and Bromley, L. *NASA Systems Engineering Handbook*, NASA/SP-2016-6105 Rev 2, 2016. [NASA Technical Reports Server record](https://ntrs.nasa.gov/citations/20170001761).

The NASA Technical Reports Server record identifies the report as public and states “Public Use Permitted.” Each excerpt keeps its page reference. The handbook PDF is not included in this repository.
