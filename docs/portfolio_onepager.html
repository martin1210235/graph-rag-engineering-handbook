Evidence-first answers with Neo4j, BM25 and optional local generation

I built a small GraphRAG prototype over selected passages from NASA's Systems Engineering Handbook. It shows how a knowledge graph can expand retrieval and keep answers tied to source pages.

What I implemented

  • A property graph of engineering concepts and typed relationships.
  • Evidence passages linked to concepts and printed handbook pages.
  • Graph-expanded retrieval followed by BM25 ranking.
  • Optional Ollama generation with instructions to answer from retrieved evidence.
  • A small, hand-labelled question set for retrieval metrics.

Design choices

  • I curated the sample graph by hand so each node and relationship can be inspected.
  • The sample is small and focused on source traceability.
  • The code does not claim automatic PDF extraction or vector search.
  • The demo can return evidence without loading a language model.

Source and scope

The sample uses short excerpts from NASA/SP-2016-6105 Rev 2. NASA's Technical Reports Server marks the report “Public Use Permitted.” The handbook PDF is not bundled. This is a standalone demo and does not contain code or data from my thesis project.
